# 📝 Text Analyzer

![Python](https://img.shields.io/badge/python-3.8+-blue)
![Status](https://img.shields.io/badge/status-active-brightgreen)

Простая консольная программа на Python для анализа текста.  
Подсчитывает количество символов, слов, предложений и находит самое длинное слово.  
Результаты сохраняются в отдельный файл в папке `reports/`.
---
## 🚀 Возможности
- Подсчёт количества **символов**
- Подсчёт количества **слов**
- Подсчёт количества **предложений** (по `.`, `!`, `?`)
- Поиск **самого длинного слова**
- Сохранение отчётов в папку `reports/`
- Возможность задать **имя файла для отчёта** или использовать авто-имя по дате и времени
