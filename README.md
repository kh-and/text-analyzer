Text Analyzer

Простая консольная программа на Python для анализа текста.  
Подсчитывает количество символов, слов, предложений и находит самое длинное слово.  
Результаты сохраняются в отдельный файл в папке `reports/`.

---

##Возможности
- Подсчёт количества символов
- Подсчёт количества слов
- Подсчёт количества предложений (по `.`, `!`, `?`)
- Поиск самого длинного слова
- Сохранение отчётов в папку `reports/`
- Возможность задать имя файла для сохранения отчёта (или использовать авто-имя по дате и времени)

---

##Установка и запуск
1. Склонируйте репозиторий:
    git clone https://github.com/ВАШ_НИК/text-analyzer.git
    cd text-analyzer
2. Запустите программу: python analyzer.py


##Пример работы

Введите текст для анализа: Привет мир. Я учу Python!
Символов: 23
Слов: 4
Предложений: 2
Самое длинное слово: Python
Введите имя файла для сохранения (Enter для авто): my_report

##Содержимое reports/my_report.txt:
Текст для анализа:
Привет мир. Я учу Python!

Символов: 23
Слов: 4
Предложений: 2
Самое длинное слово: Python
